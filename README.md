# Mochi

Un petit compagnon pour Mac qui vit sur ton Dock : habitudes, agenda, études, budget, et un assistant qui se souvient de toi et se branche sur tes outils (Calendrier d'Apple, Gmail, Google Drive, Google Agenda, Strava).

**[Télécharger Mochi.dmg](https://github.com/Tasswest/mochi/releases/latest/download/Mochi.dmg)** · [page](https://tasswest.github.io/mochi/)

macOS 14 ou plus récent, puce Apple ou Intel. Signé et notarisé par Apple.
